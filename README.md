# 皮料工艺馆 · Leather Studio

浏览器里的皮料材质库与成品预览系统,为皮具定制打样前的效果确认而设计。
TypeScript + 原生 WebGL2,无三方运行时依赖。

## 启动

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物在 dist/
```

## 六个页面

| 页面 | 功能 |
|------|------|
| 皮料库 | 增删改复制皮料,IndexedDB 本地持久化,导出/导入材质包(JSON) |
| 压纹编辑 | 荔枝纹/十字纹/鳄鱼纹程序化生成,深度/尺度/细纹/角度可调,下载 2048 PNG(颜色/法线/粗糙度/高度) |
| 做旧处理 | 在 3D 包型上用画笔刷磨损/油蜡/折痕,可撤销,遮罩随皮料保存 |
| 成品预览 | 托特/波士顿/手拿包三种程序生成包型,轨道旋转缩放,柜台射灯+日光双光源(圆盘拖方向),截图带皮料编号 |
| 色卡对比 | 两种皮料左右并排,同光源同角度 |
| 设置 | 预览分辨率,质量自检,存储管理 |

## 三项硬指标的实现方式

1. **平铺四边像素差 = 0**
   - 所有噪声在整数周期晶格上计算(`u = (fragCoord-0.5)/(size-1) × cells`),末行/列与首行/列采样同一晶格点;
   - 采样坐标再经 `mod(u, P)` 折回 `[0,P)`,消除大坐标浮点精度尾差,边缘像素**逐位相等**;
   - 法线差分按 `mod (size-1)` 环绕取邻居,边缘法线同样逐位一致;
   - 十字纹方向吸附到有理斜率 `(a,b)`,频率取 `m·√(a²+b²)/P`,保证严格周期。
2. **同一种子两次生成完全一致**:全部随机来自 shader 内整数 hash(seed, cellX, cellY),无时间、无 `Math.random`。
3. **2048 贴图 < 3 秒**:高度/法线/粗糙度/颜色全部在 GPU fragment shader 中生成,实测约 1.0–1.4 秒(含 4 张 2048² 读回)。

设置页「运行自检」可随时复验这三项。

## 目录结构

```
src/
  core/    gpu(WebGL2 基础) · shaders(压纹 GLSL) · textureGen(贴图管线+自检) · storage(IndexedDB/材质包) · types
  geom/    bags(托特/波士顿/手拿包参数化网格,弧长均匀 UV)
  render/  camera(轨道相机) · renderer(GGX PBR + 双光源) · brush(射线拾取 + 画笔盖章)
  ui/      六个页面 + 组件
```
